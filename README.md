## 🎯 Architecture Overview
This repository contains the open-source frontend viewports, context management scripts, and manifest configurations for the **SentryBERT Threat Radar Pro** Google Chrome Extension. 

To maintain absolute transparency within the developer and security compliance communities, our entire data extraction pipeline, privilege isolation mapping layers, and on-device tokenizers are fully reviewable here.

## 🔐 Zero-Egress Privacy Model
SentryBERT is engineered to execute **zero cloud data egress**. Text analysis, script parsing, and token tracking occur entirely client-side within the browser framework. The extension does not possess host matching capabilities and lacks external network routing access.

> 🏷️ **Note on Proprietary Model Binaries:**
> In compliance with enterprise parameters and to preserve structural model integrity, our customized INT8 quantized model weight arrays (`optimized_model.onnx` and `sentrybert_quantized.onnx`) are packaged directly inside the verified Chrome Web Store distribution bundle. The open framework hosted here details our exact local browser WebAssembly execution layers for independent security peer verification.
